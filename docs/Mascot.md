# 今天吃什么｜饭团吉祥物规范

这份文档定义应用中的“饭团”吉祥物。它可以出现在首页、模式选择、房间、等待、结果、空状态、加载状态、宣传海报和其他产品触点中。后续 Codex 或其他 Agent 在设计、生成或实现饭团时，应以本文件为优先参考。

## 角色定位

饭团是“今天吃什么”的陪伴型吉祥物。它代表轻松、友好、没有压力的选择过程：一个人时陪用户慢慢挑选，多人时帮助大家一起做决定。

它是一个有性格的独立角色，不是 Logo 图标的简单放大，也不是装饰贴纸。动作需要服务当前页面的功能，但保持简单、可读、容易复用。

## 外形不变量

- 主体是圆润、略带三角感的饭团轮廓，上窄下宽，顶部圆钝，不要尖锐的几何角。
- 身体上半部为米白色或暖白色，形状像一块柔软的米饭。
- 身体下半部包裹深海军蓝色海苔，海苔边缘可以有轻微弧线和不规则起伏，但不能变成衣服、裤子或复杂装备。
- 饭团背部不添加黄色圆形、光环或独立背景区域；角色本身只由米白色饭团和深海军蓝色海苔组成。
- 脸部只保留两只小而深色的眼睛和一条很短的弧形嘴巴。五官间距宽松，表情靠眼睛、嘴巴和身体姿势变化。
- 角色通常没有鼻子、耳朵、头发、手指、鞋子或复杂服饰。
- 手臂可以从海苔两侧自然伸出，使用粗圆的简化形状；手不画指节，动作保持剪影清楚。
- 腿脚只在需要站立、行走或跳跃时出现，使用短而圆的简化形状。
- 轮廓圆润、色块扁平、基本无黑色描边；可以使用柔和阴影，但不要写实高光或 3D 材质。

## 核心配色

| 部位 | 推荐颜色 | 说明 |
| --- | --- | --- |
| 米饭身体 | `#FFFDF7` / `#FFF9EC` | 暖白，不要纯冷白 |
| 海苔 | `#111827` / `#17213A` | 深海军蓝，不要纯黑 |
| 页面或动作点缀 | `#FFD21A` / `#FFDE3D` | 可用于背景、爱心或小型强调元素，不属于饭团主体 |
| 眼睛与嘴巴 | `#111827` | 与海苔统一 |
| 动作强调 | `#F4B400` 或应用主黄 | 少量使用 |

## 表情系统

饭团的表情应该克制、清楚、可重复。默认表情是两只圆点眼睛加小弧形微笑，代表友好和轻松。

允许的变化：微笑站立、认真看、开心、惊喜、轻微困惑。表情变化主要依靠眼睛、嘴巴和身体姿势，不使用复杂卡通表情或大面积文字气泡。

## 动作原则

动作必须简单，并且能在小尺寸中一眼读懂。一次只表达一个主要动词：站立、看、指、拿、等待、牵手、庆祝或挥手。

- 动作优先通过身体倾斜、眼神方向和手臂位置表达。
- 角色不要被复杂道具遮住；必要道具最多一个，例如一张菜品卡、一个房间号牌或一个结果卡。
- 角色应保持独立的轮廓和可识别的脸，不要把饭团做成 UI 图标的一部分。
- 不要默认使用击掌、拥抱、跳舞、飞行等强动作；只有页面明确需要时才使用。
- 不要为了“可爱”添加与功能无关的装饰物、服装、文字或大量彩纸。

## Web 资源规格

- 默认输出为透明背景 PNG。
- 默认画布为正方形，推荐 `256 × 256` 或 `512 × 512`；角色四周保留约 12%–18% 透明安全区。
- 角色不能贴边，不能在按钮中被裁切。
- 需要放大到海报或空状态时，再单独输出更大尺寸；不要用低分辨率按钮素材硬放大。
- `alt` 文本由页面语义提供；装饰性饭团使用空 `alt` 并标记为隐藏，不能替代按钮文字。
- 同一页面内使用同一套比例、阴影方向和角色视觉重量。

## 禁止事项

- 不得使用海鸥或参考海报中的其他品牌吉祥物。
- 不得把饭团变成普通圆形 Logo、头像圆章或两个重复图标。
- 不得添加复杂服装、拟人化五官、写实米粒、3D 金属质感或厚重描边。
- 不得让动作脱离当前页面功能。
- 不得在未确认的情况下改变饭团的主配色、海苔位置或脸部结构；不得给饭团添加背部黄色区域、光环或圆形徽章。
- 不得在生成图中依赖 AI 生成的文字传达产品信息；页面文字应由 Web 组件负责渲染。

## 质量检查清单

1. 缩小到 48px 左右时，能否看出饭团、海苔和微笑？
2. 单人和多人是否一眼可区分？
3. 多人角色是否真的有互动，而不是两张图拼接？
4. 动作是否对应页面功能，并且只表达一个主要动作？
5. 透明背景、留白、边缘和阴影是否适合 Web 使用？
6. 是否误用了参考品牌的角色、文字、水印或 UI？
