# 高德 200 条餐饮 POI 聚合面板设计

## 目标

在现有高德地图 Web MVP 上，使用附近 POI 查询接口分页获取地图中心 2 公里范围内最多 200 条餐饮数据，并用同一批查询结果展示地图、分页列表和餐饮分类聚合统计。

## 设计结论

采用当前静态 Web 方案，不增加后端和单店详情请求：

- 使用 `AMap.PlaceSearch.searchNearBy` 查询餐饮 POI。
- 使用 `pageSize: 50`，最多请求 4 页。
- 按 POI `id` 去重，累计达到 200 条后停止。
- 每次重新选择城市或点击“在此区域搜索”时清空旧结果，重新抓取。
- 地图展示当前批次所有 POI 标记。
- 列表在浏览器端按 20 条/页分页。
- 聚合面板从当前批次的 `type` 字段统计分类，不调用 `getDetails`。

高德单页结果数范围为 1–50，页码范围为 1–100；因此 200 条是本次 MVP 的抓取上限，不代表高德保证返回该范围内全部商家。

## 用户流程

1. 用户选择省份和城市，地图移动到城市中心。
2. 页面自动请求第 1 页附近餐饮 POI。
3. 页面继续请求第 2–4 页，直到满足以下任一条件：
   - 已累计 200 条去重 POI。
   - 当前页没有 POI。
   - 当前页数量少于 50 条，视为已到本次结果末页。
   - 请求失败，保留已成功获取的部分并显示部分结果状态。
4. 地图展示当前批次 POI 标记。
5. 左侧列表按 20 条/页展示，可切换上一页、下一页。
6. 聚合面板展示当前批次的分类数量。
7. 用户拖动地图后点击“在此区域搜索”，重复上述流程。

## 查询参数

每次批次查询使用：

```js
new AMap.PlaceSearch({
  city: '全国',
  citylimit: false,
  type: '餐饮服务',
  pageSize: 50,
  pageIndex: 1,
  extensions: 'all',
});

placeSearch.searchNearBy('餐饮', center, 2000, callback);
```

查询只使用 POI 搜索接口返回的数据，不对每个 POI 调用 `getDetails`。

## 数据字段

统一保留以下字段：

- `id`：用于分页结果去重。
- `name`：商家名称，用于列表展示。
- `type`：高德分类原文，用于聚合。
- `address`：地址，用于列表展示。
- `distance`：距离搜索中心的米数，用于列表展示。
- `location`：经纬度，用于地图标记。
- `hours`：查询接口返回的营业时间，没有则显示“未提供”。
- `raw`：保留原始 POI 对象，便于调试，不直接渲染。

## 分类聚合口径

从高德 `type` 字段中按 `;` 分割，取最末一级分类：

```text
餐饮服务;中餐厅;粤菜 → 粤菜
餐饮服务;火锅 → 火锅
餐饮服务 → 未细分
```

每个去重后的 POI 只计入一个最末级分类，分类数量之和等于已抓取 POI 数量。分类按数量从高到低排序；数量相同按分类名称排序。

## 页面结构

- 顶部：当前城市、数据模式、查询状态。
- 左侧上方：本次抓取数量、请求页数、是否达到 200 条上限。
- 左侧中部：分类聚合面板，显示分类名称和数量。
- 左侧下方：20 条/页的 POI 列表和分页按钮。
- 右侧：高德地图和当前批次所有 POI 标记。
- 详情面板：点击地图标记或列表项后展示该 POI 已返回的字段，不请求详情接口。

## 状态与错误处理

- 搜索中显示当前页码，例如“正在获取第 2/4 页”。
- 正常完成显示“已获取 N 条，分类 M 种”。
- 达到上限显示“已达到 200 条测试上限”。
- 少于 200 条但正常结束显示“本次接口返回 N 条”。
- 中途失败显示“已获取 N 条，第 K 页失败”，地图、列表和统计仍展示已成功数据。
- Key 或 `securityJsCode` 缺失时不发起 POI 查询，显示明确配置提示。
- 没有结果时显示空状态，不伪造演示数据覆盖真实查询失败。

## 不包含

- 不保证获得高德数据库中该范围的绝对全部商家。
- 不调用单店 `getDetails` 接口。
- 不做跨城市批量抓取。
- 不做 CSV/JSON 导出。
- 不做商家评分、推荐、收藏或登录。
- 不在地图上绘制分类热力图；第一版只展示标记和统计面板。

## 验证标准

- 选择城市后最多发起 4 页查询，每页最多 50 条。
- 最终去重结果不超过 200 条。
- 地图标记数量与去重结果数量一致。
- 列表可按 20 条/页切换，最后一页数量正确。
- 聚合分类数量之和等于去重 POI 总数。
- 同一 POI 出现在不同页时只计数一次。
- 查询接口返回营业时间时直接展示；缺失时显示“未提供”。
- 搜索失败时保留已成功数据，并明确显示失败页码和已获取数量。
