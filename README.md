# 附近吃什么 · 高德 Web MVP

这是一个只使用高德地图 Web JS API 的最小可行性产品，用来验证不同城市附近餐饮 POI 是否能返回：

- 省 / 市两级手动选择
- 城市中心 2 公里范围搜索
- 餐饮名称、类型、地址、距离
- 高德返回的营业时间；缺失时显示“未提供”
- 最多 200 条去重餐饮 POI 的地图标记
- 20 条/页的结果列表
- 餐饮分类和数量聚合面板
- 拖动地图后手动点击“在此区域搜索”

## 本地运行

1. 复制配置文件：

   ```bash
   cp config.example.js config.js
   ```

2. 在 `config.js` 填入高德 Web 端 JS API Key 和 `securityJsCode` 安全密钥。高德 JS API 2.0 的 POI 搜索必须配置安全密钥。
3. 启动静态服务器：

   ```bash
   python3 -m http.server 4173
   ```

4. 打开 <http://localhost:4173>。

没有配置 Key 时页面会展示演示数据。配置 Key 和 `securityJsCode` 后会加载高德地图，并调用 `AMap.PlaceSearch.searchNearBy`，每页请求 50 条、最多请求 4 页，最终保留不超过 200 条去重 POI。

## 快速验证

建议依次测试上海市、广东省 / 广州市、四川省 / 成都市：

1. 选择省份和城市，确认地图跳转到城市中心。
2. 确认页面按页加载数据，最终获取数量不超过 200，列表每页最多 20 条。
3. 确认分类面板中的数量之和等于已获取 POI 总数。
4. 拖动地图，确认不会立刻请求；点击“在此区域搜索”后批次重置并从第 1 页开始。
5. 点击结果卡片或地图标记，确认详情只使用查询接口已经返回的字段。
6. 找到没有营业时间的 POI 时，确认页面显示“未提供”。
7. 如果第 2–4 页失败，确认第 1 页已经获取的数据仍然保留，并显示失败页码。

200 条是上线前的测试上限，不代表高德保证返回 2 公里范围内的全部餐饮商家。

## 配置与安全

- `config.js` 只保存在本地，已加入 `.gitignore`，不要提交真实 Key。
- Web 端 Key 会出现在浏览器请求中，并不是服务端秘密；上线前请在高德控制台配置域名白名单、接口权限和调用额度。
- 真实数据是否包含营业时间取决于具体 POI 的高德数据覆盖情况，MVP 不会自行推断或补造。
